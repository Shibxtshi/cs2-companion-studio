# Use, independence and competitive-play limitations

CS2 Companion Studio is an **independent, unofficial hobby/personal project**. It is **not affiliated with, authorized, sponsored, or endorsed by Valve Corporation, Counter-Strike 2, FACEIT or OpenAI**. Names and marks are used for descriptive identification only.

The project was developed with substantial ChatGPT (OpenAI) assistance; see [AI_DISCLOSURE.md](../AI_DISCLOSURE.md). AI involvement does not provide any warranty or independent code audit.

It reads the game's Game State Integration (GSI) messages and exposes a dashboard to authenticated local browsers. It does not intentionally read game memory, inject code into the game process, or install an in-game overlay. **This is a technical description, not an anti-cheat approval or a guarantee of safety.**

Some information is estimated or delayed. Bonus-based economy predictions and optional bomb countdowns are **not official server-authoritative values**. A bomb-timing aid may confer a competitive advantage and may violate FACEIT or tournament rules. It is **disabled by default**; only activate in private tests or settings where expressly allowed. Players remain responsible for complying with game and platform rules.

For safety, use the app on localhost or a trusted LAN only; never expose the unencrypted service directly to the Internet. See [SECURITY.md](../SECURITY.md).
