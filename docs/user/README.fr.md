# Documentation utilisateur

[English](README.md) · [Index](../README.fr.md)

CCS est un Dashboard personnel dans un navigateur, pas un overlay intégré au jeu. CS2 transmet ses données GSI au serveur local ; les navigateurs authentifiés affichent les champs disponibles. La démonstration fonctionne sans partie et sans accès aux profils privés.

Les valeurs absentes ne sont pas inventées. Les prévisions économiques et le chronomètre de bombe facultatif sont des estimations. Le chronomètre est désactivé par défaut. Streamer Mode et Overlay Studio ne sont pas implémentés. Aucune approbation compétitive ni certification de sécurité n’est revendiquée.
