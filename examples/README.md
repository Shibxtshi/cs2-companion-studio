# Configuration examples

[The GSI template](gsi/gamestate_integration_companion.cfg.example) is a distributable example, not a ready-to-install private configuration.

Use the [Windows installer](../docs/guides/windows-installation.md) or `python scripts/generate_config.py` to generate unique credentials. Generated output stays in the private, ignored `cs2_cfg/` directory; .env, personal data and installation backups do not belong here.
