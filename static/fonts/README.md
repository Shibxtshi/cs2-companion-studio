# Local fonts

These original Latin WOFF2 distributions are served locally by CCS. No Google Fonts request is made by the application. The subsets support the EN/FR UI; unsupported glyphs use system fallback.

- Inter variable 400–700: Inter Project Authors, [upstream](https://github.com/rsms/inter), SIL Open Font License 1.1; retain inter-OFL.txt.
- Barlow Condensed 600 and 700: Barlow Project Authors, [upstream](https://github.com/jpt/barlow), SIL Open Font License 1.1; retain barlow-condensed-OFL.txt.

Downloaded from Google Fonts on 2026-10-28. sources.json records exact distribution URLs, sizes and SHA-256 hashes. The shipped fonts were not renamed or edited. Their own license and notices apply independently of the CCS license; do not relabel the font files under the project license. Preserve copyright, license and embedded metadata on redistribution.

The approved CCS mark is project artwork. Outlined text in the standalone lockup was generated from the distributed fonts; the application uses the same locally served families for live text.
