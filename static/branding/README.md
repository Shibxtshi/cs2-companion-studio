# Repère identity

Approved by the maintainer on 2026-10-28. The angular C and detached module represent the companion and the player's customizable dashboard.

- repere.svg: compact mark, 48-unit viewBox, Tactical Blue default; also the favicon. The header uses an alpha mask so the same shape follows every theme without duplicate image files.
- ccs-logo.svg: primary dark-background lockup, CCS / Match Center / Player Edition. Lettering is outlined and requires no font download or script when viewed on its own.

The interface uses local Barlow Condensed for the CCS wordmark and Inter for the descriptor. At small icon sizes, omit the text. The SVG files contain only paths and accessible titles, without scripts, external resources or game/team artwork.
