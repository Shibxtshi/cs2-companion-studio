Guide de démarrage

Comment commencer

  1. Lance Docker et l'installation du Companion.
  2. Installe le fichier GSI dans CS2, puis redémarre le jeu.
  3. Sur le même Wi-Fi, ouvre l'adresse de ton PC sur ton téléphone et saisis le PIN.

Tu peux aussi choisir « Voir la démo » : aucun jeu ni PIN requis.

Personnaliser

Ouvre « Mon dashboard », puis « Personnaliser » pour ajouter, déplacer et redimensionner tes widgets. Les profils sont sauvegardés dans cette instance Docker et partagés entre les appareils connectés. Tu peux aussi exporter un JSON.

En cas de problème

  • Le PIN est refusé : vérifie celui de ton installation actuelle.
  • Pas de données : vérifie le fichier GSI et redémarre CS2.
  • Le téléphone ne voit rien : vérifie que les deux appareils sont sur le même réseau privé et que l'accès LAN est autorisé.

FACEIT et confidentialité

Le Companion lit les données officielles GSI. Cela ne garantit pas que tous les widgets soient autorisés par FACEIT. Le minuteur de bombe est une estimation et nécessite une autorisation avant usage compétitif. N'ouvre pas ton port 8080 sur Internet.
