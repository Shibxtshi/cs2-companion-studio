# AI assistance & project transparency

This project is **a personal project run by one independent maintainer and shared with the community**. Its development has involved extensive collaboration with **ChatGPT (OpenAI)**.

## What AI was used for

ChatGPT provided or helped generate substantial parts of:

- Backend and frontend source code, refactoring, and debugging.
- UI/UX design, translated interface strings, and dashboard/widget behavior.
- Docker/Windows installer scripts, configuration ideas, and troubleshooting steps.
- Automated test suites and simulated data used during development.
- README, changelogs, security guidance, and release documentation.

The application was developed **iteratively with a human user testing builds** and reporting bugs. This does **not** mean all implementation details were manually reviewed, all tests are exhaustive, or the application has been independently security-audited.

## Responsibility and limitations

- The maintainer decides whether and how to release the project, reviews feedback and is responsible for the repository and releases.
- AI can suggest plausible but incorrect behavior, introduce security bugs, misunderstand game APIs, or generate incomplete documentation.
- Automated tests and synthetic GSI fixtures are not evidence of anti-cheat compatibility, independent auditing, or suitability for competitive play.
- No claim is made that **OpenAI endorses, publishes, maintains, sponsors, or is affiliated with** this project.
- No claim is made of affiliation with **Valve, Counter-Strike 2 or FACEIT**.

## Contributions using AI

Please disclose **substantial AI assistance** in pull requests and describe which parts you verified and tested. AI-assisted code is not automatically accepted: maintainers and contributors should inspect security-sensitive changes carefully and confirm they have the right to submit the code and assets.

This statement is intended to be prominent and candid, not a blanket guarantee of correctness or originality.
